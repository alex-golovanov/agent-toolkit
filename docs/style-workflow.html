Agent Toolkit / A practical walkthrough
November 6, 2026 · English Style Skills 0.1.0

How do my notes become readable prose?

You supply the ideas. The agent organizes and drafts them. A saved voice profile can then help the result sound like you. You can start without a profile or another plugin.

01 / Two inputs, different jobs

Your ideas and your voice come from different places.

A “corpus” simply means a collection of writing samples. You only need one when you want to build a reusable voice profile.

Needed for each piece

A braindump supplies the content.

Paste messy notes or a transcript. Add who the piece is for, where it will appear, and roughly how long it should be.

  • What you want to say.
  • Facts, examples, and links that matter.
  • What you are unsure about or do not want to claim.
Optional · reusable setup

Finished writing supplies the voice.

Choose English pieces that already sound like you and belong to the genre you want to write.

  • Published posts for more posts.
  • Finished essays for more essays.
  • Your own writing, with other authors filtered out.
Keep the two jobs separate. Profiling unedited braindumps can preserve the rambling you want to remove. Use finished writing to describe your voice, and raw notes to supply new ideas.
02 / The workflow for each new piece

Shape the meaning first. Apply the voice afterward.

The agent writes and edits. The plugin supplies instructions and a measurement helper; it is not a separate model or an automatic publishing service.

1 · Organize

Find the main point

The agent groups ideas, removes repetition, and marks gaps.

2 · Draft

Make it readable

The agent builds a coherent sequence, preserving the claims and uncertainty.

3 · Optional voice pass

Make it sound like you

writing-in-style applies an approved profile, if one exists.

4 · Review

Check the whole piece

You review the meaning and voice. The helper can flag measurable differences.

Illustrative example

Written for this guide. This is a prepared demonstration, not a live model run or a test of your personal voice.

Input / Fictional raw notes

“It only needed one button.”

made a tiny tool for myself. wasted an afternoon adding settings. actually only needed one button. kept thinking future me might want options. never used most of them. next time build smallest useful version then add a setting only when a real problem shows up. not all settings bad.

Brief: a short personal post for other developers. Plain English. You can reorder the notes.

No finished-writing samples or voice profile supplied.

The organizing and drafting steps can be requested in ordinary chat today. A dedicated braindump-to-draft skill was proposed as a convenience; it has not been built and is not required to try this workflow.

03 / Optional one-time setup

Save your voice so you can reuse it.

Run style-portrait on finished writing. Revisit the profile when your preferred voice or genre changes; you do not need to rebuild it for every draft.

  1. You choose the samples.Use your own English writing in the target genre. Eight texts of at least 80 words each enable per-text comparison ranges. The separate 20,000-character guideline concerns how provisional the portrait is.
  2. Python measures what can be counted.The helper counts sentence lengths, paragraph lengths, recurring markers, punctuation, and variation across samples. It does not understand the point you are making.
  3. The agent reads what the numbers cannot explain.It describes tone, humor, structure, and how you address the reader. Each observation needs evidence and a confidence level.
  4. You review the resulting rules.Accept or correct the profile before treating it as your voice. The agent then reuses it when drafting new pieces.
author-metrics.json

The measurements

Produced by Python. Used for advisory comparisons with a new draft. You do not need to edit the numbers by hand.

author-style.md

The writing instructions

Produced by the agent from the samples and measurements. Contains a voice map, evidence, and concrete “do” and “avoid” rules.

The profile stores instructions and measurements. It does not train or fine-tune a model.

Without a profile: ask for clear prose now. With a Markdown-only profile: the agent can apply the writing rules, but no numerical comparison is available. A metrics file alone does not describe your complete voice.

          How the plugin becomes available
          

            The plugin source exists locally. Creating the GitHub repository did not install the
            skills in your agent, and its commits have not been pushed. Installation or loading is a
            user action. General editing from the first request works in ordinary chat without
            installing anything.
          

          

            For a compatible agent, keep the two skill folders together so the writing skill can
            find the measurement helper. You do not need another model provider or a second plugin
            for this workflow.
          

        

        

          Optional: what the helper runs behind the scenes
          

            These commands prepare a corpus, measure it, and compare a draft. The agent still writes
            the voice map and the prose. S is the location of the
            style-portrait skill.
          

          
python3 "$S/style.py" corpus articles/ -o corpus.md
python3 "$S/style.py" metrics corpus.md --json author-metrics.json
python3 "$S/style.py" check author-metrics.json draft.md

          

            The helper needs Python 3.11+ and uses the standard library. Corpus files and profiles
            should stay out of public commits.
          

        

      


      

        

          
05 / What is proven, and what comes next

          
The next useful test is a real piece of your writing.

          

            There is enough software to try the workflow. Personal writing quality still needs to be
            judged from an actual draft and your feedback.
          

        

        

          

            ✓ Built and tested
            
Plugin mechanics

            

              Both English skills and the analyzer exist. The 45 tests cover synthetic inputs,
              imports, profile checks, CLI behavior, and relocated execution.
            

          

          

            ◇ Proposed
            
A dedicated braindump skill

            

              It would package the organizing and drafting instructions into a reusable entry point.
              The request in this guide lets you try those steps first.
            

          

          

            △ Not yet verified
            
Your voice in practice

            

              No real personal corpus, approved voice profile, or complete agent-driven writing
              trial has been evaluated in this project.
            

          

        

        

          Your acceptance test: does the draft say what you meant, read easily, and
          sound like something you would publish? The metric checker cannot answer those questions
          for you.
        

        

          What a clean numerical check does not prove
          

            Matching sentence lengths and marker rates does not establish factual accuracy, argument
            quality, humor, or voice fidelity. Short drafts under 120 words are especially noisy.
            English grammatical analysis and empirical English voice-quality calibration are not
            provided.
          

          

            The Python helper stays local and makes no network requests. The agent that reads your
            text still uses its own configured model and privacy settings.
